# Responsive Dashboard Layout

A responsive dashboard layout built with HTML and CSS Grid.



## Update


This change was made directly on GitHub.

## Features

- Responsive layout using CSS Grid Areas for a clean, semantic layout structure.
- The stats section is a grid nested inside the main dashboard grid.
- Media queries that collapses from a 3-column desktop layout to a single column mobile layout .
- Relative units (rem, fr) for flexible sizing.

## Technologies Used

- HTML5
- CSS3 (Grid, Media Queries, Nested Grid)
- Git and GitHub

## How to Run

(index.html file is not here)

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Resize the browser window to see the responsive layout change.
